# Miko Petshop - Smart Inventory Management System

Aplikasi GUI inventaris (Python, Tkinter, Matplotlib) untuk UMKM Miko Pet Shop.

## Cara menjalankan
1. Install Python 3.9 atau lebih baru (sudah termasuk Tkinter).
2. Install library:
   ```
   pip install -r requirements.txt
   ```
3. Jalankan (file `miko_petshop.py` dan `data miko petshop.xlsx` harus satu folder):
   ```
   python miko_petshop.py
   ```
